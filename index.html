Binary — Base 2

Uses only 0 and 1. Example: 101101₂ = 45₁₀.

Octal — Base 8

Uses digits from 0 to 7. Example: 55₈ = 45₁₀.

Decimal — Base 10

Uses digits from 0 to 9. It is the standard everyday number system.

Hexadecimal — Base 16

Uses 0–9 and A–F. A = 10, B = 11, C = 12, D = 13, E = 14 and F = 15.
